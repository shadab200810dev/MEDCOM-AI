# MEDCOM AI — Static Prototype

This is a browser-only prototype built with HTML, CSS, and JavaScript. It does not use Flask, Python, or a server-side backend.

## Run it

- Windows: double-click `run_medcom.bat`.
- Any browser: open `index.html`.

The six pages share synthetic demo data stored in the browser. Route planning uses JavaScript Dijkstra routing. Patient records, condition reports, road changes, events, ongoing missions, completed mission history, and analytics are simulated locally.
